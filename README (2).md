# Dashboard Operaciones Fiduciarias

## Instalacion
```bash
pip install -r requirements.txt
```

## Ejecucion
```bash
streamlit run app.py
```

## Funcionalidades
- Operaciones por proveedor
- Operaciones por fecha de grabacion
- Operaciones por negocio
- Operaciones por gestor
- Filtros dinamicos
- Tabla de detalle
